# 🍽️ Restaurant Name Generator

An interactive Python and Streamlit application that generates
unique restaurant names and complete restaurant concepts based
on user preferences.

## 📌 Project Overview

The Restaurant Name Generator allows users to customize their
restaurant idea by selecting:

- Cuisine
- Restaurant type
- Location
- Food preference
- Ambience
- Price range

The application then generates a restaurant concept including:

- Restaurant name
- Tagline
- Signature dish
- Estimated price range
- Customer rating
- Restaurant description
